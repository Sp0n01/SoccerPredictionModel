⚽ Premier League Match Predictor

Predicting home win / draw / away win using Elo ratings, rolling team form, and head-to-head history — compared across four modeling approaches, evaluated against real bookmaker odds.

01 How it works

Four stages, each building on the last. Every feature uses only information available before kickoff.

1

Elo ratings

Teams start at 1500 and update after every match, with a home-advantage adjustment and a margin-of-victory multiplier.

2

Feature engineering

Rolling form (last 5 matches), rest days, and head-to-head win rate — all leakage-safe, using only past matches.

3

Four models

A naive baseline, logistic regression, a Poisson goals model, and a random forest, trained on the same features.

4

Chronological evaluation

Trained on the past, tested on the most recent 20% of matches by date — no random split, no future leakage.
