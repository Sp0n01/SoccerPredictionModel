01 Architecture Pipeline

Every match is predicted strictly from historical signals available before kickoff.

1

Dynamic Elo Engine

Dynamic K-factor tracking, home pitch advantage shift (+65 pts), and non-linear margin-of-victory dampening.

2

Rolling Form & Fatigue

Exponential decay across recent fixtures (last 5 games), calendar rest day differential, and goal difference velocity.

3

Ensemble Modeling

Trained across Multinomial Logistic, Poisson bivariate goal expectation, and calibrated Random Forest classifiers.

4

Bookmaker Benchmark

Backtested on held-out chronological test sets against market-implied odds (Pinnacle closing lines).

03 Methodology & Data Provenance

Data is sourced from football-data.co.uk. Standard machine learning models often suffer from temporal data leakage when using shuffled K-fold splits because match results across adjacent weeks share common team states.

This pipeline enforces a chronological split: the oldest 80% of matches form the training fold, while the latest 20% are held out as an unpolluted testing horizon.
